# -spt.nashi-deti-
сделал автоматизированное прохождения SPT тестов. потомучто задрали каждый год с меня и со всех учащихся пройти этот тест и ладно еслибы не тресли пройти так ещё и учителей пинают если кто-то не прошёл так что ФАК ОФ СИСТЕМ

УСТАНОВКА: 
1) Скачайте .EXE файл
2) перенесите в удобное место
готово

КАК ПОЛЬЗОВАТЬСЯ
1) зайдите на сайт с тестом
2) запустите скрипт
3) скрипт начинает работать сразу после запуска!
4) нажимайте последовательно на ответы с 1 по 10
5) после нажмите на кнопу с потвержением
6) готово скрипт начал работать

!!!ВАЖНО!!! 
Скрипт выбирает ответы на РАНДОМ так что если натыкает что вы маньяк убийца то сори
+ скрипт надо останавливать в ручную (Просто закройте окно консоли)
